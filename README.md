# 基础综合课程在线练习

适配手机、平板和电脑。选择科目与题型后即可练习，支持固定题号跳转、随机/顺序练习、错题与收藏、记录清理、自定义错题自动移除次数以及进度导出恢复。

## 部署

仓库设置 → Pages → Deploy from a branch → main → / (root)。入口为 index.html，题库文件为 bank.js。

## 数据与隐私

此仓库只包含展示所需的题干、选项、答案、科目、题型和题目编号。不包含采集器、登录账号密码、数据库、采集日志、截图或站点维护者的个人作答记录。
每位访问者的作答、错题与收藏保存在其自己的浏览器中，不会上传或共享。跨设备使用请导出/恢复进度。清除浏览器数据会清除本机记录。

题目由个人整理，用于课程自主复习；原题版权归原权利人所有。本站不是学校官方考试入口。

## 更新

更新 index.html 和 bank.js 时保持网址和题目 id 稳定，以便保留访客本地进度。题号按所选范围内的原题号固定排序。
